# ghpatd 需求说明

- **name**：ghpatd
- **形态**：rust 单二进制文件；常驻进程的 git 客户端
- **user**：无 root 的 Linux 虚拟机中的 AI 智能体
- **目标**：让 GitHub PAT 只存在于内存，用后即焚；使用体验接近 gh 和 git

## 细节

1. 启动进程 → 生成 age 格式密钥对、打印公钥，私钥只存内存。
   每次启动重新生成密钥，不持久化、不跨运行复用。

2. 传入 pat.enc（PAT 持有者自行用 age 公钥加密，本程序不负责加密）→
   之后可用 ghpatd 开头的命令执行内置 gh 及 git 相关操作，不依赖 GitHub CLI。
   git 操作依赖本机 git 命令；git 凭据用户名固定为 x-access-token。
   可选支持 git 提交署名：启动时可指定 user.name/user.email，由程序注入 git 配置。

3. 更换 PAT：再次传入 pat.enc。

4. 结束进程 → 销毁私钥以及可能的 PAT。
   "用后即焚"指：PAT 仅在进程存活期内常驻内存，进程结束或更换时立即销毁，
   任何情况下不落盘、不进命令行参数与环境变量。

5. 日志（如提供）：
   - 默认关闭，显式开启后方可写入；
   - 存储位置可自定义；
   - 提供手动清理方式；
   - 任何情况下不得包含 PAT 明文（至多指纹）。

6. 安全边界：
   - 同 UID 进程视为可信：允许其读取 PAT、注入命令、结束进程；
   - 跨 UID 进程不可读取 PAT、不可注入命令；
   - 进程被强制杀死（如 SIGKILL）时的即时清理不作保证，依赖操作系统回收内存。
